# MyMiniApp

Личный мини-апп для Telegram: вкладка «Заказы» (Kwork, Яндекс, YouDo, Авито, hh.ru) и вкладка «Рассылка» (списки компаний, готовые сообщения в WhatsApp, статусы).

- Один файл `index.html`, без сборки и серверов.
- Данные хранятся в облаке Telegram (`CloudStorage`), вне Telegram — в памяти браузера.
- В коде нет телефонов, токенов и паролей. Списки компаний вставляются в приложении («Ещё» → «Импорт списка»).
- `?demo=1` в адресе открывает приложение на условных данных, ничего не сохраняя.

## Подключение к боту

1. В Telegram откройте @BotFather → `/newbot` и создайте бота.
2. `/mybots` → ваш бот → **Bot Settings → Menu Button → Configure menu button** и укажите адрес приложения.
3. Откройте бота, нажмите кнопку меню внизу слева.

Токен бота никому не показывайте и в код не добавляйте.
